# Classification Metrics

## 1. Confusion Matrix

A confusion matrix is a table used to evaluate the performance of a classification model.

## Key Performance Indicators (KPIs)

Based on the confusion matrix, we have the following KPIs:

### 1. Classification Accuracy
The ratio of correct predictions to total predictions.

### 2. Misclassification Rate (Error Rate)
The ratio of incorrect predictions to total predictions.

### 3. Precision
When the model predicted the positive class, how often was it correct?
- Formula: True Positives / (True Positives + False Positives)

### 4. Recall (Sensitivity)
Of all actual positive cases, how many did the model correctly identify?
- Formula: True Positives / (True Positives + False Negatives)
